### Ne yapıyorum

- **Mobil uygulama geliştirme (Flutter/Dart)** — uçtan uca: ürün planlama, ekran/UX tasarımı,
  pixel-perfect implementasyon, backend entegrasyonu, mağaza yayınlama süreci.
- **Backend & gerçek zamanlı sistemler** — PHP ve Go tabanlı API'ler, MySQL, WebSocket/WebRTC
  tabanlı mesajlaşma ve sesli iletişim altyapıları, güvenlik sertleştirme.
- **Masaüstü uygulamalar** — Rust + Tauri ile native performanslı, çapraz-platform sistemler.
- **Test & kalite mühendisliği** — golden/pixel-diff testleri, uçtan uca test piramitleri,
  otonom QA süreçleri.

### Öne çıkan

Flutter framework'ünün (Google) kendi scheduler/build pipeline'ında, `State.dispose()`
sırasında oluşan nadir bir race condition'ı bulup kök nedenini kaynak koddan izleyerek
düzelttim — açık kaynağa doğrudan katkı:
**[flutter/flutter#190172](https://github.com/flutter/flutter/pull/190172)**

Kritik/hassas değişikliklerde tek modele güvenmek yerine, birden fazla bağımsız modeli
adversarial biçimde karşılaştırıp hiçbiri hemfikir olana kadar bulguları çapraz doğrulayan bir
mühendislik disiplini uyguluyorum.
